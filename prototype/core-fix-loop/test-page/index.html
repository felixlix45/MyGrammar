What to look for

  1. The selected text is replaced in-place; caret lands right after the inserted text.
  2. Native fields (textarea/input): works even on React-controlled inputs (native-setter path). Try it on any site.
  3. contenteditable: Ctrl+Z should undo just the fix (execCommand preserves undo).
  4. Errors show in the page's / extension's DevTools console (toasts are out of scope for the prototype).
